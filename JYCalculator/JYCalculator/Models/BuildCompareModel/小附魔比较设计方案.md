# 小附魔 Enhance 比较设计方案

**创建日期：** 2026-06-25
**状态：** 方案设计完成，待实施

## 目标

在小附魔下拉框（ComboBox）中直接展示每个候选附魔相对当前已选中附魔的 DPS 收益，无需弹窗，无需异步计算。

小附魔每个只加一个属性，候选附魔和当前附魔的绝对收益都可以直接用 `DamageDeriv.ProfitList.CalcProfit(Enhance)` 线性计算；界面显示二者差值，不需要走完整 DPS 计算流水线。

## 核心思路

1. 给 `Enhance` 数据对象包一层 `EnhanceItem` wrapper，带上收益字段
2. 下拉框的 `ItemsSource` 从 `ImmutableArray<Enhance>` 换成 `ObservableCollection<EnhanceItem>`
3. `EnhanceItemView.xaml` 的 ItemTemplate 在右侧新增一列显示收益数值
4. 主窗口 DPS 计算完成后，主动刷新所有槽位的附魔收益

## 文件改动

只改 2 个文件，零新增文件。

### 1. `JX3PZ/JX3PZ/ViewModels/PzTab/EquipEnhanceViewModel.cs`

#### 1.1 新增嵌套类 `EnhanceItem`（~25 行）

```csharp
/// <summary>
/// 小附魔候选项，包一层 Enhance 加上收益计算字段
/// 透传 Enhance 的属性，保证现有 ItemTemplate 绑定不报错
/// </summary>
public class EnhanceItem
{
    public Enhance Enhance { get; set; }
    public double Profit { get; set; }
    public double ProfitPct { get; set; }
    public string ProfitColor => Profit > 0.5 ? "#229954"
        : (Profit < -0.5 ? "#C0392B" : "Gray");

    // 以下全部透传 Enhance 属性，保证现有 XAML 绑定（IconID / ItemName / Desc / Quality）不报错
    public int ID => Enhance.ID;
    public string ItemName => Enhance.ItemName;
    public string Desc => Enhance.Desc;
    public int IconID => Enhance.IconID;
    public int Quality => Enhance.Quality;
    public bool IsHaste => Enhance.IsHaste;
    public string ToolTip => Enhance.ToolTip;
    public string ShortDesc => Enhance.ShortDesc;
}
```

#### 1.2 ViewModel 新增成员

```csharp
// === 新增字段 ===
public ObservableCollection<EnhanceItem> EnhanceItems { get; private set; }
public double BaseDps { get; private set; }
private CalcResult ProfitCalcResult;

// === 构造函数中修改 ===
// 原来：
//   EnhanceSource = CollectionViewSource.GetDefaultView(AllEnhanceSource);
//   EnhanceSource.Filter = (e => IsEnhanceFit((Enhance)e));
// 改为：
EnhanceItems = new ObservableCollection<EnhanceItem>(
    AllEnhanceSource.Select(e => new EnhanceItem { Enhance = e }));
EnhanceSource = CollectionViewSource.GetDefaultView(EnhanceItems);
EnhanceSource.Filter = (e => IsEnhanceFit(((EnhanceItem)e).Enhance));

// === 新增方法 ===
/// <summary>
/// 从主计算器结果刷新所有附魔收益
/// </summary>
public void UpdateProfitsFromCalcResult(CalcResult result)
{
    if (result?.DamageDeriv?.ProfitList == null)
        return;

    ProfitCalcResult = result;
    BaseDps = result.FinalDPS;
    var selectedProfit = SelectedEnhance == null
        ? 0
        : result.DamageDeriv.ProfitList.CalcProfit(SelectedEnhance);

    foreach (var item in EnhanceItems)
    {
        item.Profit = result.DamageDeriv.ProfitList.CalcProfit(item.Enhance) - selectedProfit;
        item.ProfitPct = BaseDps > 0 ? item.Profit / BaseDps * 100.0 : 0;
    }

    // CollectionView 自动感知 ObservableCollection 的变更？不——Profit 是
    // EnhanceItem 的属性变化，需要刷新视图让绑定重新读取
    EnhanceSource?.Refresh();
}
```

#### 1.3 SelectedItem 兼容

当前 `SelectedItem="{Binding SelectedEnhance}"` 绑定的是 `Enhance` 类型。改为 `EnhanceItem` 后，需要调整 `Load()` 和 `SelectedItem` 的逻辑。

**方案**：保留 `SelectedEnhance` 为 `Enhance` 类型作为"状态"，不直接绑定 ComboBox 的 SelectedItem。改为通过 `SelectedEnhanceIndex` 联动。

实际上，`EnhanceItem.Enhance` 直接就是 `Enhance` 引用，`SelectedItem` 改为绑定到 `EnhanceItem` 类型的属性，然后在 setter 中提取 `.Enhance` 即可：

```csharp
// 新增 computed property 用于 ComboBox SelectedItem 双向绑定
public EnhanceItem SelectedEnhanceItem
{
    get => EnhanceItems?.FirstOrDefault(e => e.Enhance == SelectedEnhance);
    set
    {
        if (value == null) return;
        SelectedEnhanceIndex = EnhanceSource.Cast<EnhanceItem>().ToList().IndexOf(value);
        SelectedEnhance = value.Enhance;
        RefreshRelativeProfits();
    }
}
```

### 3. 触发时机

`PzTabItemViewModel` 或 `PzMainWindowViewModels` 中，主 DPS 计算完成后遍历所有槽位的 `EquipEnhanceVM` 调用 `UpdateProfitsFromCalcResult()`：

```csharp
// 伪代码，在主窗口 Calc 完成后
var result = CalcShell.GetCalcResult();
foreach (var slot in PzTabItems)
{
    slot.EquipEnhanceVM.UpdateProfitsFromCalcResult(result);
}
```

## 收益计算原理

`DamageDeriv.ProfitList.CalcProfit(Enhance)` 内部逻辑：

1. 根据 `Enhance.Attribute1ID` 确定属性类型（攻击/会心/破防/...）
2. 用 `DamageDeriv` 中该属性的边际收益 × `Enhance.Attribute1Value`
3. 返回单属性 DPS 变化量

界面显示的是相对收益：

```csharp
候选显示收益 = CalcProfit(候选附魔) - CalcProfit(当前选中附魔)
```

当前未选择小附魔时，当前选中附魔收益按 0 处理。因为小附魔只加一个属性，所以这个计算是精确的，不存在属性间相互影响需要考虑的情况。

## 验收标准

- [ ] 主窗口 DPS 计算完成后，小附魔下拉框每项后面显示相对当前选中附魔的收益数值
- [ ] 当前选中附魔显示为 0；未选小附魔时，候选项显示相对空附魔的收益
- [ ] 收益为正显示绿色（`#229954`），为负显示红色（`#C0392B`），约等于零显示灰色
- [ ] 切换装备后下拉框刷新，收益数值同步更新
- [ ] 不影响现有附魔筛选/选择/加载功能
- [ ] 不影响其他槽位的正常显示
